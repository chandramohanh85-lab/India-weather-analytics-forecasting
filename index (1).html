What I found

I compared temperature and rainfall patterns across Ahmedabad, Bengaluru, Chennai, Hyderabad, Jaipur, Kolkata, Lucknow, and Mumbai.

Key takeaways

  • Ahmedabad had the highest average maximum temperature, at approximately 33.6°C.
  • Bengaluru had the lowest average minimum temperature, at approximately 18.9°C.
  • Mumbai recorded the highest cumulative rainfall among the eight cities.
  • Jaipur recorded the lowest cumulative rainfall in the same period.
  • SQL aggregations helped compare monthly and yearly temperature trends, rainfall, and hottest recorded days.
Machine learning

Evaluating temperature predictions

I trained a Random Forest regression model on 2020–2024 data and evaluated it on 2,920 records from 2025.

Model performance

MetricRandom ForestBaseline
MAE0.98°C1.00°C
RMSE1.33°C1.39°C

MAE improved by approximately 1.9% over a baseline using the previous day's maximum temperature.

How I approached it

  • Prepared and sorted records by city and date.
  • Created time-based and historical features, including previous-day temperatures and recent temperature averages.
  • Trained a Random Forest model and compared its errors with a simple baseline.
  • Used MAE and RMSE to assess prediction accuracy.

This is a one-day-ahead ML evaluation using historical observations. The seven-day forecast is a separate dataset sourced from Open-Meteo.

My workflow

Tools and work completed

Analysis and data handling

  • Used Python, Pandas, and NumPy for data preparation and exploratory analysis.
  • Stored historical and forecast data in PostgreSQL.
  • Wrote SQL queries for data-quality checks, monthly and yearly averages, rainfall analysis, and hottest-day identification.
  • Used the Open-Meteo API for historical weather data and seven-day forecasts.

Dashboard and evaluation

  • Created Power BI visuals for temperature, rainfall, city comparisons, and forecast information.
  • Added model-versus-baseline evaluation and city-level error analysis.
  • Documented data coverage, metrics, and the modest improvement over the baseline.
